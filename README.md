# Music Player Project

A simple **web-based music player** built with **HTML, CSS, and JavaScript**.  
It allows you to play, pause, skip songs, and see album artwork with a progress bar.

## Features

- Play/pause functionality
- Next and previous song buttons
- Progress bar showing current time and duration
- Clickable progress bar to jump to a specific time
- Dynamic song info: title, artist, and album cover
- Responsive design for mobile and desktop

## Project Structure
music-player/
─ index.html

─ javascript.js

─ music/


  ## Notes

- Images should match the song names in `javascript.js`.  
- Works best when served via a local server (like VS Code Live Server) to avoid audio playback issues in some browsers.
